## 📁 ARQUIVOS CRIADOS

### 1. **DOCUMENTACAO_TELAS.md**
📄 **O que é**: Guia detalhado descrevendo cada tela do sistema  
🎯 **Para que serve**: Entender o que deve ser capturado em cada tela  
📋 **Conteúdo principal**:
- Descrição completa de todas as telas
- Funcionalidades implementadas em cada uma
- Elementos da interface
- Instruções de como capturar
- Checklist de capturas obrigatórias e opcionais
- Dicas para capturas profissionais
- Mapeamento de requisitos por tela

🔗 **Como usar**: 
1. Leia antes de começar as capturas
2. Use como checklist durante o processo
3. Consulte para entender qual conteúdo mostrar em cada print

---

### 2. **TEMPLATE_SECAO_TELAS.md**
📄 **O que é**: Template completo da Seção 5 formatado para Word  
🎯 **Para que serve**: Copiar e colar diretamente no seu documento  
📋 **Conteúdo principal**:
- Texto completo da seção organizado
- Subseções para cada tela
- Marcadores para inserir imagens
- Descrições técnicas das funcionalidades
- Análise de requisitos atendidos
- Parágrafos de introdução e conclusão
- Observações sobre formatação

🔗 **Como usar**:
1. Abra seu documento Word do Projeto Integrador
2. Copie o conteúdo deste arquivo
3. Cole na Seção 5
4. Substitua os marcadores [INSERIR IMAGEM...] pelas capturas reais
5. Ajuste numeração e formatação conforme seu padrão

---

### 3. **GUIA_CAPTURAS.md**
📄 **O que é**: Manual técnico passo a passo para tirar screenshots  
🎯 **Para que serve**: Garantir capturas profissionais de alta qualidade  
📋 **Conteúdo principal**:
- Preparação do ambiente (resolução, navegador, etc.)
- Ferramentas recomendadas por sistema operacional
- Instruções detalhadas para cada captura
- Configurações técnicas (formato, resolução, DPI)
- Dicas de consistência visual
- Solução de problemas comuns
- Guia de pós-processamento
- Instruções para inserir no Word

🔗 **Como usar**:
1. Leia a seção "Pré-requisitos" primeiro
2. Prepare seu ambiente conforme instruções
3. Siga passo a passo cada captura
4. Consulte "Problemas Comuns" se necessário
5. Use o checklist final antes de inserir no documento

---

### 4. **LEGENDAS_PRONTAS.md**
📄 **O que é**: Textos prontos para legendas e descrições  
🎯 **Para que serve**: Economizar tempo na redação acadêmica  
📋 **Conteúdo principal**:
- Legendas curtas e completas para cada figura
- Textos descritivos para o corpo do documento
- Exemplos de parágrafos introdutórios e conclusivos
- Tabela de mapeamento telas × requisitos
- Dicas de redação acadêmica
- Checklist de revisão textual

🔗 **Como usar**:
1. Escolha entre legenda curta ou completa
2. Copie e cole abaixo de cada imagem
3. Use os textos descritivos no corpo do documento
4. Adapte conforme necessário
5. Revise usando o checklist

## 🗺️ ROADMAP DE USO - O QUE FAZER AGORA

### FASE 1: PREPARAÇÃO (15-30 min)
```
1. [ ] Ler DOCUMENTACAO_TELAS.md por completo
2. [ ] Ler GUIA_CAPTURAS.md seção "Pré-requisitos"
3. [ ] Instalar ferramenta de captura recomendada
4. [ ] Limpar cache do navegador
5. [ ] Configurar resolução da janela (1920x1080)
6. [ ] Iniciar o sistema UniTask
7. [ ] Carregar dados demo
```

### FASE 2: CAPTURAS (1-2 horas)
```
1. [ ] Captura 1: Login (/)
2. [ ] Captura 2: Cadastro (/ > aba Cadastrar)
3. [ ] Captura 3: Dashboard (/dashboard)
4. [ ] Captura 4: Lista de Tarefas (/tasks)
5. [ ] Captura 5: Modal Nova Tarefa (/tasks > botão)
6. [ ] Captura 6: Modal Editar (/tasks > editar)
7. [ ] Captura 7: Calendário (/calendar)
8. [ ] Captura 8: Calendário Detalhes (/calendar > clicar dia)
9. [ ] [OPCIONAL] Capturas complementares (9-15)
```

### FASE 3: ORGANIZAÇÃO (15-30 min)
```
1. [ ] Renomear arquivos seguindo padrão:
       unitask-01-login.png
       unitask-02-cadastro.png
       etc.
2. [ ] Verificar qualidade (nítidas, legíveis)
3. [ ] Comprimir se necessário (TinyPNG)
4. [ ] Organizar em pasta do projeto
5. [ ] Fazer backup dos originais
```

### FASE 4: DOCUMENTAÇÃO (2-3 horas)
```
1. [ ] Abrir TEMPLATE_SECAO_TELAS.md
2. [ ] Copiar conteúdo para Word
3. [ ] Inserir imagens nos marcadores [INSERIR IMAGEM...]
4. [ ] Abrir LEGENDAS_PRONTAS.md
5. [ ] Copiar legendas para cada figura
6. [ ] Adicionar "Fonte: Elaborado pelo autor (2026)"
7. [ ] Numerar figuras sequencialmente
8. [ ] Ajustar formatação (tamanho, centralização)
9. [ ] Criar referências cruzadas no texto
10. [ ] Revisar ortografia e gramática
```

### FASE 5: REVISÃO FINAL (30-60 min)
```
1. [ ] Verificar se todas as 8 capturas obrigatórias estão inseridas
2. [ ] Conferir numeração sequencial das figuras
3. [ ] Validar que cada figura tem legenda
4. [ ] Verificar que cada figura é mencionada no texto
5. [ ] Revisar mapeamento de requisitos
6. [ ] Verificar formatação ABNT (se aplicável)
7. [ ] Ler seção completa em voz alta (detecta erros)
8. [ ] Solicitar revisão de colega ou professor orientador
9. [ ] Fazer ajustes finais
10. [ ] Salvar versão final + backup
```

## 💡 DICAS DE OURO

### ✨ Para Capturas
1. **Faça tudo de uma vez** - Mantém consistência visual
2. **Use modo demo** - Dados contextualizados e realistas
3. **Capture mais do que precisa** - Melhor sobrar que faltar
4. **Nomeie imediatamente** - Evita confusão depois

### ✨ Para Documentação
1. **Copie e adapte** - Use os textos prontos como base
2. **Seja específico** - Mencione cores, posições, elementos
3. **Referencie requisitos** - Mostre que implementou tudo
4. **Use voz ativa** - "O sistema apresenta..." (não "É apresentado...")

### ✨ Para Apresentação
1. **Pratique navegação** - Saiba onde está cada função
2. **Tenha sistema rodando** - Demo ao vivo impressiona
3. **Prepare GIFs/vídeos** - Backup se algo der errado
4. **Destaque diferenciais** - Sistema de lembretes, filtros, etc.
