# 🚀 Quick Start - UniTask

Guia rápido para começar a usar e documentar o UniTask em **15 minutos**.

---

## ⚡ INÍCIO RÁPIDO - 3 Passos

### 1️⃣ Executar o Sistema (2 min)

```bash
# Instalar dependências (primeira vez)
npm install

# Iniciar servidor
npm run dev

# Acessar
# http://localhost:5173
```

### 2️⃣ Testar com Modo Demo (1 min)

1. Clique em **"Entrar no Modo Demo"**
2. Pronto! Sistema carregado com dados

### 3️⃣ Navegar pelas Telas (5 min)

- 🏠 **Dashboard**: Visão geral
- 📋 **Tarefas**: Lista e gerenciamento
- 📅 **Calendário**: Visualização temporal

---

## 📸 CAPTURAS DE TELA - 5 Passos

### 1️⃣ Preparar (3 min)
```bash
# Limpar cache
F12 > Application > Local Storage > Clear

# Recarregar
F5

# Modo demo
Clicar "Entrar no Modo Demo"
```

### 2️⃣ Capturar Telas Obrigatórias (30 min)

#### Atalho Windows: `Win + Shift + S`
#### Atalho Mac: `Cmd + Shift + 4`

1. Login: `/`
2. Cadastro: `/` > aba "Cadastrar"
3. Dashboard: `/dashboard`
4. Lista: `/tasks`
5. Modal Nova: `/tasks` > botão "Nova Tarefa"
6. Modal Editar: `/tasks` > ícone lápis
7. Calendário: `/calendar`
8. Detalhes: `/calendar` > clicar em dia

### 3️⃣ Nomear Arquivos
```
unitask-01-login.png
unitask-02-cadastro.png
unitask-03-dashboard.png
unitask-04-lista-tarefas.png
unitask-05-modal-nova-tarefa.png
unitask-06-modal-editar-tarefa.png
unitask-07-calendario.png
unitask-08-calendario-detalhes.png
```

### 4️⃣ Inserir no Word
```
1. Inserir > Imagens > selecionar arquivo
2. Redimensionar: 15-16cm largura
3. Centralizar
4. Adicionar legenda abaixo
```

### 5️⃣ Legendas Prontas

Copie de **LEGENDAS_PRONTAS.md**

Exemplo:
```
Figura 1: Tela de login do sistema UniTask.
Fonte: Elaborado pelo autor (2026).
```

## 📝 DOCUMENTAÇÃO - 3 Passos

### 1️⃣ Copiar Template (5 min)
```
Abrir: TEMPLATE_SECAO_TELAS.md
Copiar todo o conteúdo
Colar no Word na Seção 5
```

### 2️⃣ Inserir Imagens (30 min)
```
Substituir [INSERIR IMAGEM: ...]
Por suas capturas de tela
```

### 3️⃣ Revisar (15 min)
```
Verificar:
- Todas as imagens inseridas ✓
- Legendas corretas ✓
- Numeração sequencial ✓
- Ortografia ✓
```

## 🆘 PROBLEMAS COMUNS

### Sistema não inicia?
```bash
# Deletar node_modules e reinstalar
rm -rf node_modules
npm install
npm run dev
```

### Dados demo não aparecem?
```bash
# Limpar LocalStorage
F12 > Application > Local Storage > Clear All
F5 (recarregar)
Clicar "Entrar no Modo Demo"
```

### Imagem borrada?
```
- Zoom do navegador em 100% (Ctrl+0)
- Resolução 1920x1080
- Salvar como PNG (não JPG)
```
